# Pixel Snake — ретро-змейка

Небольшая браузерная игра на HTML, CSS и JavaScript. Не требует сборки, библиотек или сервера: достаточно открыть `index.html`.

## Файлы
- `index.html` — структура страницы.
- `style.css` — оформление и адаптация под мобильные устройства.
- `script.js` — логика змейки, еда, столкновения, очки, пауза и рекорд.

## Управление
- Стрелки или `W A S D` — движение.
- `Пробел` — пауза/продолжить.
- `Enter` — новая игра после проигрыша.
- На телефоне доступны экранные кнопки.

## Публикация через GitHub Pages
1. Войдите на https://github.com/ или создайте аккаунт.
2. Нажмите **+** → **New repository**.
3. Назовите репозиторий, например `pixel-snake`. Выберите **Public** и нажмите **Create repository**.
4. В репозитории нажмите **Add file** → **Upload files**.
5. Перетащите в окно GitHub три файла: `index.html`, `style.css`, `script.js`. Нажмите **Commit changes**.
6. Откройте **Settings** → **Pages**.
7. В разделе **Build and deployment** выберите **Deploy from a branch**. В качестве ветки выберите `main`, папку — `/(root)`, затем нажмите **Save**.
8. Подождите несколько минут. В разделе Pages появится адрес сайта вида `https://ВАШ-ЛОГИН.github.io/pixel-snake/`.
9. Откройте ссылку в новой вкладке и проверьте, что игра запускается. Отправьте эту ссылку преподавателю.

Важно: имя пользователя в URL должно совпадать с вашим GitHub-логином, а регистр имён файлов — с тем, как они указаны в HTML. Сама публикация не выполняется автоматически при скачивании проекта.
